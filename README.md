# MismoAdmin
A PHP-based administation console for managing Mismo Messaging System instances.


### Requirements:
- Apache 2.4.x
- PHP 8.x with support for MongoDB
- git (for obtaining the source code)

### Installation:
Obtain the source from GitHub:
> git clone https://github.com/tjeaster81/MismoAdmin.git

Edit the MismoAdmin configuration file and adust the values to represent your environment.
> $EDITOR $MISMOADMIN/MismoAdmin.conf.php
